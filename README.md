# NumenHand

NumenHand is an ultra-light, glove-shaped mouse that redefines ergonomic interaction. Instead of gripping a traditional device, the user simply wears it, keeping the hand in a natural and relaxed position while reducing strain from prolonged use.

Equipped with capacitive sensors, NumenHand provides effortless click input and interprets finger gestures to emulate scrolling and advanced interactions — eliminating the need for a physical scroll wheel or heavy mechanics.

Its minimal, wearable design makes it significantly lighter than conventional mice, offering a seamless blend of comfort, precision, and next-generation usability.

## Materials

- ESP32 C3 (v2.0.17)
- Optic Sensor PWM3395
- Touch Sensor TTP223 (x3)

## LIBRARIES

- ESP32 BLE Mouse: https://github.com/T-vK/ESP32-BLE-Mouse (v0.3.1)
